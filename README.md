# Sentiment Analysis Dashboard

A data analysis and Machine Learning project focused on analyzing textual data, identifying sentiment patterns, and visualizing insights through interactive dashboards.

## About the Project

This project was built to explore how data analysis and Machine Learning can be used together to understand public opinions, reviews, and feedback from textual data.

The project mainly focuses on preprocessing and analyzing text data, extracting meaningful insights, and visualizing sentiment trends using Power BI dashboards. Machine Learning techniques were additionally used to classify text into positive, negative, and neutral sentiments.

The goal of the project is to combine data analysis, NLP preprocessing, visualization, and ML-based prediction into a complete analytical workflow.

---

## Features

* Text data preprocessing and cleaning
* Exploratory analysis of sentiment trends
* TF-IDF feature extraction
* Sentiment classification using Machine Learning
* Interactive Power BI dashboards
* Visualization of analytical insights
* Sentiment prediction with 84.5% accuracy

---

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* TF-IDF
* Power BI
* Matplotlib
* Machine Learning

---

## Project Workflow

1. Load and analyze textual dataset
2. Perform data cleaning and preprocessing
3. Explore sentiment distributions and trends
4. Convert text into numerical features using TF-IDF
5. Train and evaluate Machine Learning model
6. Generate sentiment predictions
7. Visualize insights and trends using Power BI dashboards
